# Ajudivas — Design system

Componentes do aplicativo **Ajudivas**, reconstruídos a partir do arquivo Figma
[Projeto IHC](https://www.figma.com/design/h2E2rFkNY3qruR8t0gIyAl/Projeto-IHC)
(página **Componentes**, node `1012:320`), cruzados com a
`Lista de requisitos.md` (RF01–RF10 / RNF01–RNF10).

O objetivo do app é apoiar o deslocamento seguro de mulheres em situação de
vulnerabilidade: mostrar rotas, registrar ocorrências e dar acesso rápido ao
modo pânico.

## Princípios de design

1. **Uma mão, metade inferior.** Ações principais (pânico, rotas, navegação)
   ficam abaixo da dobra, com alvos ≥ 44 px (RNF01).
2. **Segurança codificada por cor + forma + texto.** Roxo = seguro,
   laranja = atenção, vermelho = perigo. Nunca só a cor (WCAG 1.4.1 / RNF09).
3. **Baixa carga cognitiva.** Uma decisão por tela, linguagem direta, ícones
   acompanhados de rótulo (RNF03).
4. **Acessibilidade não é opcional.** Contraste ≥ 4.5:1 para texto, foco
   visível, escala de texto e alto contraste em um toque (RNF02).
