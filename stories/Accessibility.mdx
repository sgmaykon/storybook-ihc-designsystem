(RNF02). Este documento mapeia cada critério aplicável, mostra o contraste

## Contraste medido

Razões calculadas com a fórmula WCAG 2.1 (luminância relativa) em
`contrastRatio()` de `stories/tokens.ts`. O requisito para texto normal é
**4.5:1**; para texto grande (≥ 18.66 px bold / 24 px) é **3:1**; para
componentes não textuais é **3:1**.

<ContrastTable />

### Resumo

- **100% dos pares em uso no Design System são aprovados:**
  - **16 pares aprovados em AA (≥ 4.5:1)** — todo texto da interface passa com folga (incluindo `--ajd-color-warning-strong` `#9A3412` com **7.31:1** e `--ajd-color-danger-strong` `#B91C1C` com **6.47:1**).
  - **2 pares aprovados para Ícones / Elementos Gráficos (≥ 3:1 — WCAG 1.4.11)** — `--ajd-color-warning` (`#E46962`) e `--ajd-color-danger` (`#DC2626`) restritos exclusivamente a marcadores e ícones.
  - **2 pares Decorativos / Isentos (WCAG 1.4.11)** — divisórias `#E7E1F0` e borda redundante `#D0BCFF` (a seleção também é comunicada por fundo `#FFFFFF`, selo e `aria-checked`).

### Diretrizes Material aplicadas

- **Alvos de toque:** 48 × 56 px (Material recomenda 48 dp).
- **Rótulo sempre visível:** ícone + texto; nunca só o ícone.
- **Estados:** `hover` (elevação), `pressed` (`aria-pressed`), `focus`
  (anel duplo), `disabled` (opacidade + `aria-disabled`).
- **Tipografia:** Roboto, no máximo 3 pesos por tela.
- **Movimento:** durações de 120–320 ms com easing padrão; respeita
  `prefers-reduced-motion`.
