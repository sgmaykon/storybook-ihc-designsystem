export const SearchBarDemo = () => {
  const [state, setState] = useState('repouso');
  const [value, setValue] = useState('');

  return (
    <DemoBox label="Interativo · Experimente clicar, digitar ou escolher uma sugestão">
      <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap', justifyContent: 'center' }}>
        {(['repouso', 'edicao', 'pesquisado']).map((s) => (
          <button
            key={s}
            type="button"
            onClick={() => {
              setState(s);
              if (s === 'pesquisado' && !value) setValue('Casa da Vânia');
              if (s === 'repouso') setValue('');
            }}
            style={{
              padding: '6px 12px',
              borderRadius: 999,
              border: '1px solid var(--ajd-color-outline-strong)',
              background: state === s ? 'var(--ajd-color-primary)' : '#fff',
              color: state === s ? '#fff' : 'var(--ajd-color-text-primary)',
              font: '600 12px var(--ajd-font-family)',
              cursor: 'pointer',
            }}
          >
            Estado: {s}
          </button>
        ))}
      </div>
      <div style={{ width: '100%', maxWidth: 358 }}>
        <SearchBar
          state={state}
          value={value}
          onChange={(next) => {
            setValue(next);
            setState(next ? 'edicao' : 'repouso');
          }}
          onSuggestionSelect={(suggestion) => {
            setValue(suggestion.label);
            setState('pesquisado');
          }}
          onSubmit={() => setState('pesquisado')}
        />
      </div>
    </DemoBox>
  );
};

## Máquinas de estado

### SearchBar e AppHeader

```text
repouso ──focus/click──▶ edicao ──digita──▶ edicao (sugestões filtradas)
   ▲                       │  │
   │                       │  └──Esc / blur──▶ repouso
   │                       └──Enter / lupa──▶ pesquisado ──limpar──▶ repouso
   └─────────────────────────────limpar──────────────────────────────┘
```

- **Repouso:** placeholder “Para onde você vai?”; lupa à esquerda.
- **Em edição:** borda primária de 2 px, botão **X** para limpar,
  dropdown com “Sugestões recentes” e lista filtrada.
- **Pesquisado:** termo aplicado, contador de resultados, **X** para limpar.
- Teclado: `↓`/`↑` percorre sugestões, `Enter` confirma, `Esc` fecha.
- ARIA: `role="combobox"`, `aria-expanded`, `aria-activedescendant`,
  `aria-controls`; cada opção é `role="option"`.

### RouteSheet

```text
Rota segura (padrão) ⇄ Rota insegura
        │                    │
        └── Iniciar rota ────┴──▶ Mapa (Iniciar rota)
```

- Duas opções em um `radiogroup`; a selecionada ganha borda
  `--ajd-color-outline-strong`, fundo branco, selo e `aria-checked`.
- **Rota segura:** selo “Recomendada”, roxo, métricas de iluminação e
  movimento de pessoas.
- **Rota insegura:** selo “Cuidado”, fundo de atenção, alerta em
  `--ajd-color-warning-strong`.
- **Iniciar rota** é o CTA fixo na metade inferior (RNF01).

### NavBar

```text
Início │ Feed │ Pânico │ Contatos úteis │ Ajustes
```

- Item ativo: pílula `#EADDFF`, ícone e rótulo em `#6750A4`, `aria-current="page"`.
- **Pânico:** botão elevado de 56 px, sempre visível, com `aria-label`
  “Acionar pânico” e texto oculto explicando o discador de emergência.
- Alvos: 70 × 76 px por item; toda a barra fica na metade inferior da tela.

### OccurrenceMarker / OccurrenceDetails

```text
Marcador (Grave | Média) ──toque──▶ Detalhes (Grave | Médio) ──X──▶ mapa
```

- **Grave:** vermelho `#DC2626`, ícone de alerta, contador de relatos.
- **Média:** laranja `#E46962` no preenchimento, texto em `#9A3412`.
- Detalhes trazem título, foto com selo “Relatado há…”, fatores de risco e
  avaliação por estrelas.
- O fechamento devolve o foco ao marcador que abriu o painel.

### AccessibilityToolbar

```text
texto 85 % ⇄ 100 % ⇄ 125 %
contraste padrão ⇄ alto contraste
voz desligada ⇄ ligada
mapa detalhado ⇄ simplificado
```

- Um único `tab stop`; setas movem o foco, `Home`/`End` vão às pontas.
- Alterações são anunciadas em `aria-live="polite"`.

## Fluxo de telas

```text
Ajudivas · Início
   ├── Home (Mapa Interativo)
   │     ├── toque no marcador ──▶ Home (Detalhes Ocorrência Grave)
   │     │        └── X ──▶ Home (Mapa Interativo)
   │     ├── toque no marcador ──▶ Home (Detalhes Ocorrência Média)
   │     └── busca ──▶ Home (Rotas Opções)
   │              ├── rota segura ──▶ Home (Rota + Detalhes Ocorrência)
   │              └── Iniciar rota ──▶ Mapa (Iniciar rota) ──▶ Mapa (Chegada)
   ├── Feed Comunitário
   └── Pânico ──▶ discador de emergência
```

## Regras de interação

1. **Feedback imediato.** Todo toque responde em ≤ 120 ms (hover/pressed).
2. **Sem gestos obrigatórios.** Nenhuma ação depende de swipe; gestos são
   atalhos opcionais (WCAG 2.5.1).
3. **Confirmação para ações destrutivas.** Pânico pede confirmação por voz e
   vibração antes de discar.
4. **Foco devolvido.** Painéis e sheets devolvem o foco ao elemento de origem.
5. **Estados nunca só por cor.** Sempre há texto, ícone ou atributo ARIA.
6. **Uma decisão por tela.** A próxima ação é sempre o elemento de maior
   contraste/destaque (RNF03).
