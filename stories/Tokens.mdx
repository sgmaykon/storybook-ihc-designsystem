# Design tokens

Todos os valores vêm do arquivo **Projeto IHC** e são expostos como custom
properties CSS com prefixo `--ajd-`. O arquivo `stories/tokens.css` é a única
fonte de estilos globais; `stories/tokens.ts` traz as mesmas tabelas tipadas.

```css
/* exemplo */
.qualquer-elemento {
  color: var(--ajd-color-primary);
  background: var(--ajd-color-surface);
  font: var(--ajd-font-weight-medium) var(--ajd-font-size-body) var(--ajd-font-family);
}
```

## Cores

### Marca e ações

Cores institucionais e de ação do aplicativo. Destaques (selos, badges e pílulas ativas) usam `--ajd-color-highlight-bg` e seu texto contrastante `--ajd-color-highlight-text`.

### Estados e gravidade

Convenção do RNF09: **seguro = roxo**, **atenção = laranja**,
**perigo = vermelho**. Cada estado tem um token de *preenchimento* (ícones,
barras) e um token *forte* para texto pequeno.

<ColorTable
  tokens={colorTokens.filter(
    (color) => color.token.includes('danger') || color.token.includes('warning'),
  )}
/>

> **Ajuste de acessibilidade:** o laranja original do Figma (`#E46962`) tem
> **3.23:1** sobre branco — reprovado para texto pequeno. Por isso o token
> `--ajd-color-warning-strong` (`#9A3412`, **7.31:1**) é usado em textos, e o
> laranja fica restrito a preenchimentos/ícones grandes. O selo usa
> `#4F378B` sobre `#EADDFF` (**7.23:1**).
